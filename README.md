# Калькулятор фьючерсов Аристокс

Основной вариант — нативный HTML-блок для страницы Tilda `invest.aristocks.ru/calc`.

- `tilda-calculator-embed.html` — готовый автономный блок T123.
- `fallback-contracts.json` — полный резерв параметров контрактов.
- `trader-calculator.js` — исходная логика автоматического обновления параметров.
- `TILDA-INSTALL.md` — установка и проверка.

Калькулятор отображается сразу из встроенных данных, затем обновляет параметры из открытого источника. Cloudflare Worker не участвует в критическом пути.

Старая самостоятельная версия для Cloudflare сохранена в остальных файлах проекта.
