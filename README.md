# Калькулятор фьючерсов Аристокс

Самостоятельная индексируемая страница на `calc.aristocks.ru`.

- Статика находится в `public/` и обслуживается Cloudflare Static Assets.
- `/api/futures` получает параметры контрактов из MOEX ISS.
- Последняя успешная версия хранится в Cloudflare KV и обновляется по запросу или каждые 15 минут.
- Локальная проверка: `pnpm dev`.
