# Установка калькулятора на Tilda

## 1. Страница

1. Создайте в проекте Tilda новую страницу.
2. Укажите адрес страницы: `calc`.
3. Добавьте блок **Другое → T123 «HTML-код»**.
4. Откройте файл `tilda-calculator-embed.html`, скопируйте его целиком и вставьте в T123.
5. Опубликуйте страницу.

Код уже содержит интерфейс, стили, оба режима расчёта, поиск, 470 резервных контрактов и справочный текст. Iframe и внешние CSS/JS не используются.

## 2. SEO

- В Tilda откройте: **Настройки страницы → Главное**.
- Заголовок страницы: `Калькулятор фьючерсов MOEX — размер позиции и риск`
- Описание страницы: `Бесплатный калькулятор фьючерсов Московской биржи: рассчитает количество контрактов, размер позиции, риск по стоп-лоссу и требуемое гарантийное обеспечение.`
- Блок T123 не изменяет Title и Description: значения задаются только в настройках страницы Tilda.
- В разделе **Facebook и SEO → Вид в поисковой выдаче** укажите тот же заголовок и описание.
- Адрес: `https://invest.aristocks.ru/calc`
- Canonical: `https://invest.aristocks.ru/calc`
- Индексация страницы: разрешена.
- Язык страницы/сайта: `Русский` (`lang="ru"`).
- После сохранения обязательно нажмите **Опубликовать**.

Если страница будет открываться на другом адресе, замените адрес в canonical.

После публикации:

1. Добавьте ссылку `Калькулятор фьючерсов` с главной страницы или из раздела бесплатных материалов.
2. В Яндекс Вебмастере отправьте `/calc` на переобход.
3. В Google Search Console откройте проверку URL и запросите индексирование.
4. Sitemap уже должен содержать `https://invest.aristocks.ru/calc`.

## 3. Как обновляются данные

1. Калькулятор сразу запускается со встроенным резервом.
2. В фоне браузер запрашивает актуальные параметры из открытого источника.
3. Успешный ответ сохраняется в браузере пользователя.
4. Если источник временно не отвечает, остаются последние успешные или встроенные данные.

Cloudflare Worker в загрузке страницы и расчёте не участвует.

## 4. Проверка после публикации

- Открыть страницу без VPN с телефона и компьютера.
- Убедиться, что калькулятор появляется сразу.
- Ввести `SI`: первым должен быть `Si-9.26`.
- В режиме «Количество по риску» проверить расчёт по входу, стопу и допустимому убытку.
- В режиме «Риск и итог позиции» указать направление и количество: без стопа должны считаться стоимость позиции и результат точек выхода.
- Добавить прибыльную и убыточную точки выхода; при введённом стопе должен появиться итоговый показатель риска / прибыли.
- Переключить риск с `%` на `₽`: поле счёта должно скрыться.
- Проверить статус: `Данные · актуальны` либо `Данные · резерв`.
- Проверить ссылку «Нашли ошибку?» и ссылки на Telegram, MAX и VK.

## 5. Обновление встроенного резерва

Файл `fallback-contracts.json` — полный резерв на момент сборки. Его нужно обновлять периодически, чтобы калькулятор оставался полезным даже при недоступности источника. На втором этапе это можно автоматизировать.
